# Aniimo · Calculadora de madeira

[Usar a calculadora](https://qevzi.github.io/aniimo-calculator/)

Planeje a coleta de madeira para melhorar o RV em Aniimo. A calculadora usa o nível do RV, o estoque e o cultivo para estimar quanto falta e quanto tempo a coleta pode levar. Disponível em português, inglês e japonês.

O site é estático e está em `index.html`. Abra esse arquivo no navegador para testar localmente.

O [guia Noite Mágica](https://qevzi.github.io/aniimo-noite-magica/) é um projeto separado.

Projeto de fã mantido por qevzi, desenvolvido com auxílio do OpenAI Codex.
