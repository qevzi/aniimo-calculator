Créditos e informações

Ferramenta gratuita de fã para a comunidade de Aniimo, sem vínculo oficial com o jogo.

Imagens: respectivos titulares, obtidas no MetaForge. Dados: Aniimax, de aebii (MIT).

Resultados estimados; confira no jogo. O estoque salvo fica neste navegador. Serviços externos podem receber dados técnicos de conexão.

Privacidade

Não solicitamos nome, e-mail, senha ou conta de jogo. Ao clicar em “Salvar Dados”, as configurações e o estoque são gravados no armazenamento local deste navegador. Na configuração atual, não há sincronização em nuvem habilitada. Os dados permanecem até serem substituídos ou até você apagar os dados deste site nas configurações do navegador. “Zerar Estoque” altera os valores na tela; para atualizar um estoque já salvo, salve novamente.

Esta ferramenta não inclui publicidade ou análise de audiência próprias. Fontes, bibliotecas e parte das imagens são carregadas de serviços externos: Google Fonts, Google/Firebase (módulos técnicos), Tailwind CSS, unpkg e MetaForge. Ao entregar esses arquivos, os provedores recebem informações técnicas da conexão, como endereço IP. O código de sincronização Firebase só é ativado quando uma configuração específica é fornecida pelo ambiente, o que não ocorre nesta versão publicada como HTML independente. Se hospedado no GitHub Pages, o GitHub também registra endereços IP para segurança, conforme sua política de privacidade. Os serviços externos seguem suas próprias políticas; os estoques não são enviados a eles pelo código da calculadora nesta configuração.
